# WMS-Lite Manual

Orbiflow WMS-Lite customer-facing functional manual. The site explains WMS modules from business scenarios and connects each explanation to the corresponding product page.

## Preview locally

Run a static HTTP server in this directory, then open the local URL in a browser. For example:

```powershell
python -m http.server 4173
```

Open `http://127.0.0.1:4173/`.

## Project structure

- `index.html`: manual content and page structure
- `styles.css`: visual system and responsive layout
- `app.js`: navigation, tabs, and screenshot lightbox behavior
- `assets/`: product screenshots and supporting images
